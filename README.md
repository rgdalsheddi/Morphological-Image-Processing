# Morphological-Image-Processing

This lab focuses on morphological image processing using Python and OpenCV. We apply different morphological operations to a binary image and compare the results using square and circular kernels.

Tools and Libraries

Python

OpenCV (cv2)

NumPy

Matplotlib

Google Colab / Jupyter Notebook

Tasks

Task 1: Square Kernel

Apply four morphological operations using a 5×5 square kernel:

Erosion

Dilation

Opening

Closing

Task 2: Circular Kernel

Apply the same four operations using a circular kernel with radius 5.

Task 3: Comparison

Compare the results of the square and circular kernels and explain how kernel shape and size affect the image.

Results

Erosion makes white objects smaller.

Dilation makes white objects larger.

Opening removes small white noise.

Closing fills small black gaps and holes.

Square and circular kernels produce different results depending on their shapes and sizes.

How to Run

Download the .ipynb notebook.

Open it in Google Colab or Jupyter Notebook.

Run all cells.

View the resulting images and comparisons.

Conclusion

In this lab, we learned how morphological operations change binary images. We also compared square and circular kernels to understand how different kernel shapes affect the results.
